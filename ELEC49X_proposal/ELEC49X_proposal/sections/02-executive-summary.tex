\UnnumberedSection{Executive Summary}
\Guidance{Aim for approximately three-quarters of a page. Summarize the project, the contents of this proposal, two or three main milestones, and the estimated total cost. Write this section after drafting the body.}

AI coding agents increasingly follow \emph{agent skills}: \texttt{SKILL.md} files of natural-language instructions that an agent loads when it judges that a task matches the skill's description. Public GitHub repositories held 3.8 million skill files within nine months of the format's release. Skills are written mainly in prose, no compiler checks them, and they spread by being copied between repositories. Software engineering has long judged source code with metrics such as size, churn, age, clone coverage, and readability, but it is not known whether these metrics carry over to skills. This project uses the GitSkills dataset from the Mining Software Repositories (MSR) 2027 Mining Challenge to determine which of these metrics have meaningful equivalents for skills and how their distributions compare with source code.

The end product is a reproducible Python pipeline with documented metric definitions, visualizations, and a report; submission to the challenge is conditional on a readiness review. The pipeline filters the dataset, calculates each metric in its own module, and joins the results into one metrics file. Size, churn, age, clone coverage, and readability are each adapted to prose instructions and checked by hand on samples before any finding relies on them. Work proceeds iteratively from the 13,000-skill sample to the full dataset: definitions reviewed (M1, November 6, 2026), sample pipeline integrated (M4, November 20), initial analysis (M6, December 4), and a validated, reproduced final pipeline (M12, March 12, 2027). The scope excludes the SpecMine dataset, readability scoring of non-English skills, running skills, and causal claims about skill quality.

Pilots on the sample have already informed the size, churn, and readability methods. Verification compares calculations with reference values, injected faults, repeat runs, and resource limits, while validation uses the hand-checked samples to establish what each metric can support. The dataset and tools are free, so the estimated total cost is \$0~CAD. Remaining learning covers large-scale data handling, text-similarity and readability measurement, and non-parametric statistics.
