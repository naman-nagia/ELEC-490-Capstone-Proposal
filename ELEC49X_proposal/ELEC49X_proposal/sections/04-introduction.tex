\CourseSection{Introduction}\label{sec:introduction}

\CourseSubsection{MSR Challenge and Project Motivation}

The Mining Software Repositories (MSR) Mining Challenge invites researchers to investigate development practices using shared software repository datasets. The 2027 challenge provides SpecMine, containing natural-language specifications for agent-assisted development, and GitSkills, containing instructions and supporting material for AI agents. Suggested research questions provide starting points for participants' own investigations~\cite{msr2027MiningChallenge}. Our team will use GitSkills to study how agent instructions are written, reused, and maintained in software environments. These findings could help developers and researchers identify patterns in the development and evolution of this emerging software artifact.

\CourseSubsection{Project Objective and Research Direction}\label{sec:project-objectives}

The project builds on MSR's question of whether established software metrics such as size, churn, age, clone coverage, and readability, have meaningful equivalents for agent skills. The team will first investigate each metric independently, then examine their distributions and relationships to guide further research and inform conclusions. Potential analyses include how instruction complexity relates to revision activity and how duplicated content is distributed across skill collections. The engineering objective is to develop a reproducible pipeline that processes and validates data, calculates metrics, and produces visualizations supporting conclusions about skill development, reuse, and maintenance.

\CourseSubsection{Scope and Deliverables}

The initial scope is to explore GitSkills and assess which metrics support meaningful analysis of agent instructions. Research questions and scope will be refined based on available data and preliminary results. Deliverables include documented metric definitions, reproducible analysis code, visualizations, and a report interpreting the findings. Data availability will determine which analyses can be completed, and the report will explain the limitations of the measurements and conclusions.
